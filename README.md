</h4>

<br>

### Sobre o projeto



O **ARChemie** é uma ferramenta educacional desenvolvida na engine **Unity**, com uso das bibliotecas **ARFoundation** e **Unity Sentis**, voltada ao ensino de Química Orgânica.

<br>

O aplicativo utiliza `Realidade Aumentada (RA)` e um modelo de `Inteligência Artificial (ARGOS)` para reconhecer estruturas moleculares montadas a partir de peças físicas e apresentar seus modelos tridimensionais.
